Embedded Line-Following Robot

An Arduino-based embedded robotics project developed for autonomous line following. The system combined infrared sensor feedback, PID motor control, hardware integration, and a Node-RED dashboard for real-time monitoring and interaction.

Overview

This project involved developing an embedded system for autonomous line following using Arduino-based hardware. The robot used infrared sensors to detect the line, PID control to stabilise movement, and motor control logic to follow the path more smoothly than a simple on/off steering approach.

System Development

The project was developed in stages. The first stage focused on basic autonomous movement and PID tuning. The second stage added a Node-RED dashboard for real-time monitoring and interaction. A later extension explored basic OpenCV techniques for object detection and visual response.

Key Features

  • Infrared sensor-based line detection.
  • PID motor control for improved path stability.
  • Arduino-based embedded control logic.
  • Real-time monitoring and interaction through a Node-RED dashboard.
  • Hardware integration, testing, and debugging.
  • Basic OpenCV object detection experimentation.

My Contribution

I implemented and tuned the PID control behaviour, worked on the Node-RED interface, integrated and tested hardware components, and contributed to debugging and validation of the complete robot system.

What I Learned

This project strengthened my understanding of embedded control systems, sensor feedback, practical robotics debugging, PID tuning, hardware/software integration, and the value of real-time interfaces when testing physical systems.
