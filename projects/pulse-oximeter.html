Pulse Oximeter Prototype

A group embedded-systems project investigating physiological signal acquisition and monitoring using STM32 microcontroller peripherals, UART communication, and FPGA subsystem development.

Overview

This group project explored an embedded pulse oximeter prototype, combining microcontroller-based signal acquisition with communications and FPGA-related subsystem work. The emphasis was on practical implementation, monitoring, integration, and laboratory testing.

Technical Approach

The project involved STM32 peripherals including ADC and DMA for sampled data acquisition, UART for communication, and FPGA development using Quartus Prime. Oscilloscope observations supported testing and debugging during development.

Key Engineering Elements

  • STM32-based analogue signal acquisition using ADC and DMA.
  • UART communication as part of the embedded integration work.
  • FPGA subsystem development using Quartus Prime.
  • Laboratory signal observation and debugging with an oscilloscope.

My Contribution

I primarily developed the communication and signal-processing components, handling the transfer of acquired pulse data and processing it into readable measurements displayed through a command-line interface. This included integrating the SpO₂ calculation, managing signal conditioning behaviour, and implementing measures to improve reading stability during finger placement.

Engineering Challenges

A key challenge was integrating the SpO₂ calculation with the signal-conditioning pipeline. The high-pass filter introduced a settling period, during which the DC offset affected the reliability of initial measurements. I addressed this by delaying calculations until the filter output had stabilised. Another challenge was sudden signal disturbances caused by finger placement. I implemented a plausibility check that detected changes exceeding a defined threshold and rejected these transient readings, allowing the system to display a subsequent valid measurement instead.

What I Learned

The project strengthened my understanding of microcontroller peripherals, data acquisition, serial communication, FPGA workflows, and verification of embedded systems through physical testing.
